## Tentang

Repository ini berisi beberapa contoh proyek Arduino yang dapat digunakan sebagai referensi pembelajaran maupun pengembangan proyek elektronik.

## Project

### 👁️ OLED Eyes Animation

Animasi mata robot menggunakan display OLED SSD1306 128×64 dengan beberapa ekspresi seperti:

- Normal
- Berkedip
- Marah
- Sedih
- Senang

### 🚪 RFID Door Lock

Sistem kunci pintu menggunakan modul RFID RC522 dan Servo.

Fitur:

- Membaca kartu RFID
- Membuka pintu menggunakan Servo
- LED indikator akses diterima
- LED indikator akses ditolak
- Mendukung beberapa UID kartu

# 🇺🇸 English

## About

This repository contains several Arduino projects for learning and educational purposes.

All source code is written in **Arduino C++** and is compatible with the Arduino IDE.

## Projects

### 👁️ OLED Eyes Animation

A robot eye animation displayed on a 128×64 SSD1306 OLED screen featuring:

- Neutral
- Blink
- Angry
- Sad
- Happy

### 🚪 RFID Door Lock

An RFID-based door lock system using an RC522 RFID reader and a servo motor.

Features:

- RFID card authentication
- Servo-controlled door lock
- Access granted indicator
- Access denied indicator
- Supports multiple RFID card UIDs
